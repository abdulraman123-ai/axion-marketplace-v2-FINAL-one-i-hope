# VoxKit — ChatGPT Writing Workflow

VoxKit is a skills-only plugin package for a reusable writing workflow in ChatGPT-compatible plugin environments. It helps transform spoken thoughts, dictated transcripts, and rough notes into clear writing, summaries, study notes, debate preparation, professional messages, and replies.

## Package contents

- `plugin.json`: portable plugin manifest.
- `skills/voxkit-writing/SKILL.md`: core workflow instructions.

## Important

This is a **package draft**, not a published listing. To distribute through the official ChatGPT Plugins directory, upload the ZIP through the developer portal, complete identity verification, address automated findings, and submit it for review. Approval and public availability are not guaranteed.

This package has no MCP server, no API key, no Gemini integration, no OpenAI API dependency, and no separate inference billing configured. It relies on the AI capabilities available in the host environment. Availability of skill/plugin installation depends on the host and the user's account.

## Use

1. Extract the package ZIP.
2. Review the manifest and skill instructions.
3. For official ChatGPT directory distribution, upload the package in the Plugins developer portal and follow the automated validation and review flow.
4. Do not advertise it as an official OpenAI product or say it is published until the listing is approved and available.

## Product direction

VoxKit is designed as a portable digital product for ChatGPT workflows, not a standalone website that requires the seller to pay for every AI request.
